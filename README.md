# 🎮 Марк: Голодная Голова (Mark: The Hungry Giant Head)

Веселая аркадная игра на чистом HTML5 Canvas и Web Audio API.

## 🕹️ Об игре
Марк — гигантская ненасытная голова. Он ползает по парку и офисному району и поглощает всех подряд:
- 👔 Офисников
- 🛴 Самокатчиков
- 🍕 Курьеров с пиццей
- 👵 Бабушек
- 🌯 Божественную шаурму

## ⌨️ Управление
- **Движение**: Мышь (курсор) или клавиши `W A S D` / `Стрелочки`
- **Турбо-Кусь (ускорение)**: `Пробел` или зажатая `ЛКМ`
- **Пауза**: `P` или кнопка на экране
- **Звук**: переключатель в углу экрана

## 🚀 Запуск
Просто откройте `index.html` в любом современном браузере. Никаких сторонних библиотек, серверов и зависимостей!
